# 显示 OpenRouter 模型

OpenRouter 模型出现在 Copilot Chat 模型选择器的 **OpenRouter** 供应商下。

若看不到：

1. 运行 **OpenRouter: 设置 API Key**。
2. 打开语言模型管理：**Chat: 管理语言模型**（`workbench.action.chat.manage`）。
3. 运行 **OpenRouter: 刷新模型列表**。

未配置 Key 时，模型可能显示警告图标。

模型 ID 为 OpenRouter slug（如 `deepseek/deepseek-chat`）。完整目录：[openrouter.ai/models](https://openrouter.ai/models)。
