# Show OpenRouter models

OpenRouter models appear under vendor **OpenRouter** in the Copilot Chat model picker.

If they are missing:

1. Set your API key — **OpenRouter: Set API Key**.
2. Open language models manager: Command Palette → **Chat: Manage Language Models** (`workbench.action.chat.manage`).
3. Run **OpenRouter: Refresh Model List**.

Without an API key, models may show a warning icon until the key is configured.

Model IDs are OpenRouter slugs (e.g. `deepseek/deepseek-chat`). Full list: [openrouter.ai/models](https://openrouter.ai/models).
