# Set your OpenRouter API key

1. Create a key at [openrouter.ai/keys](https://openrouter.ai/keys).
2. Run **OpenRouter: Set API Key** from the Command Palette.

The key is stored in VS Code SecretStorage (OS keychain), not in `settings.json`.

| Command | Action |
| ------- | ------ |
| **OpenRouter: Set API Key** | Set or update key |
| **OpenRouter: Clear API Key** | Remove stored key |
| **OpenRouter: Open API Key Page** | Open openrouter.ai/keys |
| **OpenRouter: Query Usage** | Open openrouter.ai/activity |

After setup, run **OpenRouter: Refresh Model List** if models do not appear.
